AnswerQuestionUseCase.execute() — step by step

1

Route the query

router.route(query) → RouteDecision with one or more of: sql, semantic, clarify.

2

Clarification short-circuit

If the router returns CLARIFY, return immediately — no retrieval needed.

3

Gather evidence in parallel

asyncio.gather() fans out to every matched strategy concurrently. SQL and semantic results arrive at the same time for hybrid queries.

4

Merge evidence

Evidence.merge(results) combines rows and passages into one normalized object regardless of source.

5

Synthesize the answer

synthesizer.synthesize(query, evidence, decision) → Answer with prose + deterministic citations from provenance.

SqlGuard — Security Boundary

Not a prompt instruction — a hard code boundary

  • Single statement only — no semicolon-chaining
  • Read-only: blocks DELETE, UPDATE, DROP, INSERT, DDL
  • Table allowlist: unknown tables are rejected
  • Mandatory LIMIT injected on every SELECT
  • SQLite connection opened read-only as defense in depth
